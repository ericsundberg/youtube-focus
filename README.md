# YouTube Focus

A lightweight browser extension for Firefox-based browsers
that allows users to toggle the YouTube homepage feed.

## Objectives

- Provide a distraction-free YouTube homepage.
- Preserve normal search and navigation functionality.
- Allow users to restore the homepage feed at any time.
- Persist user preferences locally.
- Minimize browser permissions and dependencies.
- Avoid collecting or transmitting user data.

## Development

This project follows the programming requirements defined in
AGENTS.md and the modular-development skill located at
.agents/skills/modular-development/SKILL.md.

Development is local-first, modular, and incremental.
